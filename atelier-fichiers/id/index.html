FAQ

Apakah file saya dikirim ke server?

Tidak. Semua konversi, kompresi, dan penyuntingan dilakukan langsung di perangkat Anda. Aplikasi tidak pernah mengirim file apa pun melalui internet.

Apakah perlu koneksi internet?

Tidak, semua alat berfungsi secara offline. Hanya fitur terjemahan yang mungkin meminta Anda mengunduh bahasa untuk pertama kali dari pengaturan Apple, dan pembelian Atelier Pro dilakukan melalui App Store.

Apa saja yang termasuk dalam versi gratis?

Semua alat, tanpa watermark, dengan batas 3 operasi per hari. Atelier Pro menghapus batas ini.

Saya berganti perangkat, bagaimana cara mendapatkan Atelier Pro kembali?

Buka layar Atelier Pro dan ketuk “Pulihkan Pembelian”. Gunakan Akun Apple yang sama dengan yang Anda gunakan saat membeli.

Bagaimana cara menghapus riwayat?

Di riwayat, geser sebuah baris untuk menghapusnya, atau gunakan “Hapus semua riwayat”.
