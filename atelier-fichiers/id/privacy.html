Kebijakan Privasi

Atelier Fichiers · Terakhir diperbarui: 2026-10-22

Bahasa lain ↓

Ringkasnya

Atelier Fichiers tidak mengumpulkan, menyimpan di server, maupun mengirimkan data pribadi apa pun. Semua pemrosesan file dilakukan di perangkat Anda. Pengembang tidak memiliki akses ke file Anda maupun ke informasi apa pun tentang Anda.

File Anda

File yang Anda buka di aplikasi (dokumen, PDF, gambar, audio, video, arsip…) diproses secara lokal dan disimpan di lokasi yang Anda pilih. Aplikasi tidak pernah mengirimnya melalui internet.

Riwayat operasi hanya disimpan di perangkat Anda. Anda dapat menghapusnya kapan saja dari dalam aplikasi.

Izin yang diminta

Setiap izin hanya diminta saat Anda menggunakan fitur terkait, dan Anda dapat mencabutnya di Pengaturan perangkat Anda.

  • Kamera: untuk memindai dokumen dan membaca kode. Gambar tetap berada di perangkat.
  • Foto (hanya tambah): untuk menyimpan gambar hasil konversi ke pustaka foto Anda. Aplikasi tidak membaca pustaka foto Anda; Anda sendiri yang memilih foto untuk diimpor.
  • Pengenalan Ucapan: untuk mentranskripsi rekaman Anda menjadi teks dan membuat subtitle. Transkripsi dilakukan di perangkat, tanpa mengirim apa pun.
  • Pemberitahuan: untuk memberi tahu Anda saat pemrosesan yang lama telah selesai. Pemberitahuan ini dibuat secara lokal.

Fitur cerdas dan terjemahan

Ringkasan, ekstraksi resep, atau pembacaan kartu nama menggunakan model Apple Intelligence yang terpasang di perangkat. Terjemahan menggunakan layanan terjemahan Apple di perangkat: hanya pengunduhan bahasa yang melewati Apple. Dalam kedua kasus tersebut, teks Anda tidak pernah dikirimkan ke pengembang.

Pembelian dalam aplikasi

Pembelian Atelier Pro sepenuhnya ditangani oleh Apple melalui App Store. Aplikasi hanya memeriksa apakah pembelian telah dilakukan; aplikasi tidak menerima data pembayaran apa pun. Penghitung operasi gratis disimpan di perangkat Anda.

Iklan dan pelacakan

Atelier Fichiers tidak memuat iklan, pelacak, maupun alat analitik atau statistik penggunaan apa pun.

Anak-anak

Aplikasi ini tidak mengumpulkan data apa pun dan cocok untuk semua usia.
