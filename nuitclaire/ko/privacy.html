개인정보 처리방침

Nuit Claire · 최종 업데이트: 2026-10-22

다른 언어 ↓

요약

Nuit Claire는 어떠한 개인정보도 수집하지 않고, 자체 서버도 없어요. 계산(위성 통과, 천체 위치, 완전한 어둠)은 모두 기기에서 이루어져요. 아래에 설명한 몇몇 공개 서비스에는 꼭 필요한 정보만 보내요.

내 위치

위치는 위성 통과, 밤 시간대, 내 하늘의 날씨를 계산하는 데 쓰여요. 앱이 열려 있을 때만 사용되고 기기에만 저장돼요.

날씨를 위해 약 1 km 단위로 반올림한 위치가 Open-Meteo와 7Timer!에 전송돼요. 위치 권한을 거부하고 직접 도시를 고를 수도 있는데, 이때는 입력한 이름이 Open-Meteo의 도시 검색 서비스로 전송돼요.

사용하는 서비스

앱은 다음 서비스에서 공개 데이터를 내려받아요. 식별자나 개인정보는 전송되지 않지만, 모든 인터넷 연결이 그렇듯 요청의 IP 주소는 해당 서비스에 보여요.

  • Open-Meteo: 구름 예보와 도시 검색(반올림한 위치 또는 도시 이름).
  • 7Timer!: 천문 예보(반올림한 위치).
  • CelesTrak: 위성 궤도.
  • NOAA SWPC: 태양 활동과 오로라 예보.
  • Minor Planet Center: 혜성 궤도.

요청하는 권한

각 권한은 해당 기능을 사용할 때만 요청되고, 기기의 설정에서 언제든지 철회할 수 있어요.

  • 위치: 위 내용을 참고하세요. Apple Watch에서는 나침반을 위성 쪽으로 향하게 하는 데도 쓰여요.
  • 카메라: '어디를 볼까' 화면의 표시 뒤로 실제 하늘을 보여 줘요. 이미지는 전혀 저장되지 않아요.
  • 동작: '어디를 볼까' 화면을 내가 향하고 있는 하늘 쪽으로 맞춰 줘요.
  • 캘린더(추가만): 내가 고른 천문 이벤트를 추가해요. 앱은 캘린더를 읽지 않아요.
  • 로컬 네트워크: 망원경의 Wi-Fi 어댑터에 연결해 망원경을 조준해요. 내 네트워크 밖으로는 아무것도 나가지 않아요.
  • 알림: 통과, 오로라, 맑은 밤 알림으로, 기기에서 생성돼요.

내 일지와 iCloud

관측 일지(여기에 추가한 사진 포함), 즐겨찾는 장소, 설정, 관측 모임은 기기에 저장돼요. iCloud 동기화를 켜면 다른 기기에서도 볼 수 있도록 Apple이 관리하는 내 iCloud 계정에도 저장돼요. 개발자는 여기에 접근할 수 없어요.

공유한 관측 모임

관측 모임을 공유하면 링크에 초대 정보가 담겨요: 제목, 장소 이름과 좌표, 날짜, 내 이름 또는 닉네임, 메모. 링크를 받은 사람은 누구나 이 정보를 볼 수 있어요. 이 사이트의 초대 페이지는 서버에 저장하지 않고 브라우저에서 바로 보여 줘요. 이 사이트는 GitHub Pages에서 호스팅되며, GitHub Pages는 기술적인 접속 기록을 보관할 수 있어요.

광고 및 추적

Nuit Claire에는 광고, 추적기, 분석 도구나 사용 통계 도구가 전혀 없어요.

어린이

이 앱은 어떠한 데이터도 수집하지 않으며 모든 연령대에 적합해요.

변경 사항

이 방침이 바뀌면 새 버전을 업데이트 날짜와 함께 이 페이지에 올릴게요.
