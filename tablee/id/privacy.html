Kebijakan Privasi

Bahasa lain ↓

Ringkasnya

Tablée tidak mengumpulkan data pribadi apa pun. Aplikasi ini bekerja secara offline, tidak terhubung ke server mana pun, dan tidak memerlukan akun. Semua yang Anda masukkan tetap ada di perangkat Anda, kecuali jika Anda memilih untuk membagikan atau mengekspornya.

Data Anda

Aplikasi menyimpan permainan Anda, poin dan aturannya, daftar pemain Anda (nama, emoji, warna), statistik yang dihitung dari permainan tersebut, serta pengaturan Anda. Nama pemain boleh apa saja sesuai keinginan Anda: nama itu hanya berguna bagi Anda.

Data ini disimpan di perangkat Anda, dan pengembang tidak dapat mengaksesnya. Seperti data aplikasi lain, data ini dapat ikut tersimpan dalam cadangan perangkat Anda jika Anda mengaktifkannya. Anda dapat menghapus semuanya di pengaturan; menghapus aplikasi juga menghapusnya.

Berbagi, ekspor, dan impor

Tidak ada yang keluar dari aplikasi tanpa tindakan dari Anda.

  • Membagikan permainan: gambar atau teks dikirim melalui fitur iOS (AirDrop, Messages, Mail…) dan berisi nama pemain beserta poin mereka.
  • Ekspor: file JSON atau CSV berisi permainan Anda dan nama para pemain. Anda memilih tempat penyimpanannya; file itu lalu tunduk pada ketentuan layanan yang Anda pilih.
  • Impor: aplikasi hanya membaca file yang Anda pilih.

Izin yang diminta

Tablée tidak meminta izin apa pun: tidak kamera, tidak lokasi, tidak kontak, tidak foto.

Iklan, pembelian, dan pelacakan

Tablée gratis. Aplikasi ini tidak berisi iklan, pembelian dalam aplikasi, pelacak, maupun alat analitik atau statistik penggunaan.

Anak-anak

Aplikasi ini tidak mengumpulkan data apa pun dan cocok untuk segala usia.

Perubahan

Jika kebijakan ini berubah, versi barunya akan diterbitkan di halaman ini beserta tanggal pembaruannya.
