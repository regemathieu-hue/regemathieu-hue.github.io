データの収集

Convert Everything は、個人データを収集、保存、送信することは一切ありません。アプリはお使いのデバイス上で完全にローカルに動作します。

使用するデータ

アプリがアクセスするのは次のリソースのみです：

  • インターネット — 公開 API から為替レートを取得するためにのみ使用します。個人データは送信されません。

サードパーティのサービス

為替レートは、無料の公開 API である fawazahmed0/exchange-api から提供されています。このリクエストの際にユーザーデータが送信されることはありません。

広告とトラッキング

Convert Everything には、広告、トラッカー、行動分析 SDK は一切含まれていません。

お子様について

このアプリはデータを一切収集せず、あらゆる年齢の方に適しています。
