FAQ

Les taux de change sont-ils mis à jour en temps réel ?

Les taux de change sont actualisés à chaque ouverture de l'app si une connexion internet est disponible. Une connexion internet est requise pour obtenir les taux les plus récents.

L'app fonctionne-t-elle sans internet ?

Oui, toutes les conversions sauf les devises fonctionnent hors ligne. Les taux de change utilisent le dernier taux mis en cache.

Comment changer la langue de l'app ?

La langue peut être changée directement dans les paramètres de l'app. Plus de 16 langues sont disponibles.
