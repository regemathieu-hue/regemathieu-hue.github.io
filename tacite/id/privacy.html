Kebijakan Privasi

Tacite · Terakhir diperbarui: 2026-11-12

Bahasa lain ↓

Ringkasan

Tacite tidak mengumpulkan data pribadi apa pun. Aplikasi ini berjalan secara offline, tidak terhubung ke server mana pun, tidak meminta akun, dan tidak memiliki akses ke rekening bank Anda. Semua informasi yang Anda masukkan tetap ada di iPhone Anda, kecuali jika Anda memilih untuk mengekspornya.

Data Anda

Aplikasi ini menyimpan langganan yang Anda masukkan (nama, harga, mata uang, frekuensi, tanggal, kategori, warna, metode pembayaran, dan catatan) serta pengaturan Anda. Bidang « metode pembayaran » adalah teks bebas: jangan pernah memasukkan nomor kartu di sini.

Data ini disimpan di iPhone Anda, dalam ruang yang hanya dapat diakses oleh widget Tacite, dan pengembang tidak memiliki akses ke data tersebut. Seperti data aplikasi lainnya, data ini bisa termasuk dalam cadangan iPhone Anda jika fitur cadangan telah diaktifkan. Menghapus aplikasi akan menghapus semua data tersebut.

Notifikasi

Pengingat berupa notifikasi lokal: mereka dijadwalkan dan ditampilkan langsung oleh iPhone Anda tanpa melalui server mana pun. Notifikasi ini berisi nama langganan, jumlah pembayaran, dan tanggal pemotongan. Anda dapat menonaktifkannya kapan saja melalui pengaturan iOS.

Ekspor

Tidak ada data yang keluar dari aplikasi tanpa tindakan Anda. Ekspor CSV berisi langganan Anda: Anda memilih tempat untuk mengirim atau menyimpannya, dan file tersebut akan tunduk pada ketentuan layanan yang dipilih.

Izin yang Diminta

Tacite hanya meminta izin untuk menampilkan notifikasi, guna pengingat. Tidak ada izin kamera, lokasi, kontak, atau foto.

Iklan, Pembelian, dan Pelacakan

Tacite gratis. Aplikasi ini tidak memiliki iklan, pembelian dalam aplikasi, pelacak, atau alat analitik atau statistik penggunaan.

Anak-anak

Aplikasi ini tidak mengumpulkan data apa pun dan cocok untuk semua usia.

Perubahan

Jika kebijakan ini berubah, versi terbaru akan diterbitkan di halaman ini dengan tanggal pembaruan.
