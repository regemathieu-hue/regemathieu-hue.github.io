Kebijakan Privasi

Sound Level · Terakhir diperbarui: 2026-11-12

Bahasa lain ↓

Ringkasan

Sound Level tidak mengumpulkan data pribadi apa pun. Aplikasi ini berfungsi secara offline, tidak terhubung ke server mana pun, dan tidak memerlukan akun. Mikrofon hanya digunakan untuk menghitung tingkat kebisingan: tidak ada suara yang direkam atau dikirim.

Mikrofon

Aplikasi ini meminta izin akses mikrofon untuk mengukur kebisingan. Suara dianalisis secara langsung di iPhone, lalu segera dilupakan: suara tersebut tidak pernah direkam, disimpan, atau dikirim ke mana pun.

Anda dapat mencabut izin ini kapan saja di Pengaturan › Privasi dan Keamanan › Mikrofon. Aplikasi tidak akan bisa mengukur setelah itu.

Data Anda

Aplikasi menyimpan pengukuran Anda: tanggal, tingkat kebisingan per detik, nama dan catatan yang Anda berikan, serta pengaturan Anda (pembebanan, ambang, kalibrasi).

Data ini disimpan di perangkat Anda, dan pengembang tidak memiliki akses ke dalamnya. Seperti data aplikasi lain, data ini dapat termasuk dalam cadangan perangkat Anda jika Anda telah mengaktifkannya. Anda dapat menghapus setiap pengukuran di riwayat; menghapus aplikasi akan menghapus semua data tersebut.

Bagikan dan Ekspor

Tidak ada yang keluar dari aplikasi tanpa tindakan Anda.

  • Bagikan ringkasan: teks dilewatkan melalui alat iOS (AirDrop, Pesan, Mail…) dan berisi tanggal, tingkat kebisingan, puncak, serta catatan pengukuran.
  • Ekspor CSV: file berisi waktu dan tingkat kebisingan setiap detik. Anda memilih tempat menyimpannya atau siapa yang dikirimkan; file tersebut kemudian tunduk pada ketentuan layanan yang dipilih.

Iklan, pembelian, dan pelacakan

Sound Level gratis. Aplikasi ini tidak mengandung iklan, pembelian dalam aplikasi, pelacak, atau alat analitik atau statistik penggunaan.

Anak-anak

Aplikasi ini tidak mengumpulkan data dan cocok untuk semua usia.

Perubahan

Jika kebijakan ini berubah, versi terbaru akan diterbitkan di halaman ini beserta tanggal pembaruan.
