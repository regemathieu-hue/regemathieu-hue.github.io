Vanliga frågor

Varför visar appen inte signalstyrkan?

iOS lämnar inte ut den råa signalstyrkan för Wi-Fi till appar. Wi-Fi-karta mäter därför vad ditt Wi-Fi faktiskt levererar på varje plats: hastighet och latens. Poängen från 0 till 100 som visas på kartan kommer från de två mätningarna.

Vad används kameran till?

Den gör att iPhone kan följa din position medan du går. Inga bilder sparas eller skickas. Om du helst inte vill använda den, eller om din enhet inte klarar den här spårningen, välj ”Med fingret” innan du börjar: då flyttar du din position genom att dra fingret över kartan.

Varför ber appen om min plats?

iOS kräver det här tillståndet för att en app ska kunna läsa Wi-Fi-nätverkets namn. Det används inte till något annat: appen läser inte dina GPS-koordinater. Om du nekar fungerar skanningen ändå, men utan att visa nätverkets namn.

Hur mycket data går åt vid en skanning?

Ungefär 1 MB per sekund med standardinställningarna, alltså cirka 300 MB för en skanning på 5 minuter. Om du vill använda mindre öppnar du Inställningar (kugghjulet på startskärmen) och väljer ”250 kB (sparsam)” under ”Data per mätning”.

Använder skanningen 4G eller 5G?

Nej. Mätningarna går bara via Wi-Fi. Om Wi-Fi tappas faller mätvärdet till 0 i stället för att mäta mobilnätet, och kartan visar det.

Kartan är förskjuten eller spårningen försvinner: vad gör jag?

Gå långsamt med iPhone framför dig och rikta den mot ställen med detaljer snarare än en slät vägg. Under skanningen visar appen vad du behöver rätta till, till exempel ”Rör dig lite långsammare”. På långa sträckor kan spårningen driva iväg lite: det är bättre att göra flera korta skanningar än en enda mycket lång.

Kartan är röd överallt: beror det på mitt Wi-Fi?

Inte nödvändigtvis. Mätningarna går via en server på internet, så en långsam internetanslutning eller hög latens påverkar hela bostaden. Det är skillnaderna mellan rummen som avslöjar Wi-Fi-nätets svagheter.

Hur delar, byter jag namn på eller tar bort en skanning?

Öppna skanningen från startskärmen. Delningsknappen högst upp på skärmen skickar den som en bild, och menyn bredvid låter dig byta namn på den eller ta bort den.

Kan jag använda en annan testserver?

Ja, i Inställningar › Testserver. Servern måste returnera det antal byte som begärs via parametern ”bytes”.

Integritetspolicy

Wi-Fi-karta samlar inte in några personuppgifter och innehåller varken reklam, köp eller spårare. Dina skanningar stannar på din enhet. För att mäta hastigheten laddar appen ned data från en testserver, som precis som vilken webbplats som helst ser din IP-adress.
