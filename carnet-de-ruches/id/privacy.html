Kebijakan Privasi

Catatan Peternak Lebah · Terakhir diperbarui: 2026-11-24

Bahasa lain ↓

Singkatnya

Catatan Peternak Lebah tidak mengumpulkan data apa pun. Semua catatan Anda di aplikasi tetap berada di iPhone atau iPad Anda.

  • Tidak perlu akun, tidak ada iklan, tidak ada pelacakan: aplikasi ini tidak memiliki alat analitik atau iklan, dan tidak mengidentifikasi Anda dengan cara apa pun.

Buku catatan dan register Anda

Informasi usaha peternakan Anda (nama, alamat, nomor peternak lebah, SIRET, telepon, dokter hewan), peternakan lebah, stup, pemeriksaan, pengobatan, panen, serta perpindahan koloni disimpan di penyimpanan pribadi aplikasi, di perangkat Anda. Data ini tidak dikirim ke siapa pun, bahkan tidak kepada pengembang.

Menghapus aplikasi akan menghapus seluruh buku catatan. File tersebut dapat termasuk dalam cadangan iCloud atau lokal perangkat Anda, yang dikelola sendiri melalui pengaturan Apple.

Ekspor dan Cadangan

PDF register dan file cadangan hanya dibuat saat Anda meminta, dan Anda yang memilih tempat menyimpannya atau siapa yang dikirimkan. File tersebut berisi informasi usaha peternakan Anda: aplikasi tidak lagi memiliki kendali atas file setelah Anda membagikannya.

Notifikasi

Pengingat akhir pengobatan dijadwalkan pada perangkat; tidak ada server yang terlibat.

Tautan ke pendaftaran stup

Tombol "Daftar Online" membuka halaman situs service-public.gouv.fr di browser Anda. Aplikasi tidak mengirimkan informasi apa pun ke situs tersebut; situs ini menerapkan kebijakan privasi sendiri.

Pembelian

Catatan Peternak Lebah Pro dijual dan dikelola oleh Apple. Aplikasi tidak melihat metode pembayaran atau identitas Anda; aplikasi hanya membaca, melalui App Store, apakah pembelian telah dilakukan, untuk membuka fitur.

Anak-anak

Catatan Peternak Lebah tidak mengumpulkan data apa pun, termasuk dari anak-anak.

Perubahan

Jika kebijakan ini berubah, versi baru akan diterbitkan di halaman ini beserta tanggal pembaruan.
